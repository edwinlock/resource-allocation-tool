Slider Responses

Contents: All resource allocation decisions from the slider exercise (treatment group parent sessions only), including economic parameters and computed outcomes.

Format: One row per scenario response with columns for parent_session_id, family_id, scenario number, display order, child 1/2 investments, completion timestamp, scenario parameters (gamma, sigma, theta), pre-earnings for both children, computed alpha, and final earnings (individual and aggregate).

📋 Usage Notes
  • All CSV files use UTF-8 encoding and include header rows
  • Timestamps are in ISO 8601 format (YYYY-MM-DDTHH:MM:SS)
  • NULL values appear as empty cells in the CSV
  • JSON arrays and objects in survey responses are stringified
  • child_sessions.csv and parent_sessions.csv link to survey_responses.csv via session_id
  • parent_sessions.csv links to slider_responses.csv via session_id
  • The enumerators.csv file links to both session files via enumerator_id

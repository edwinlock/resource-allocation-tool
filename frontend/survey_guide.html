Survey JSON Format Guide

Basic Survey Structure

{
    "survey_id": "surveyName",
    "name": "Survey Display Title",
    "questions": [
        // Array of question objects
    ]
}

Variable Substitution

Use {variableName} in any text field to inject session data:

Variable Description Example
{child1name} Child 1’s name “Sarah”
{child2name} Child 2’s name “John”
{child1ability} Child 1’s ability score 75
{child2ability} Child 2’s ability score 45
{child1school} Child 1’s school “Lincoln Elementary”
{child2school} Child 2’s school “Washington Middle”
{participant} Participant ID “P001”
{enumerator} Enumerator ID “E001”
{sessionType} Session type “treatment” or “control”

Question Types

1. open - Single text/number input

{
    "question_id": "unique_id",
    "type": "open",
    "query": "What is {child1name}'s favorite subject?",
    "datatype": "text",  // or "number"
    "required": true
}

2. multiopen - Multiple inputs with labels

{
    "question_id": "hours_spent",
    "type": "multiopen",
    "query": "Hours per week spent on:",
    "prefixes": [
        "Helping {child1name} at {child1school}",
        "Helping {child2name} at {child2school}"
    ],
    "datatype": "number",
    "required": true
}

Note: For rating/satisfaction questions, consider using multilikert instead of multiopen with numbers.

3. singleselect - Radio buttons (one choice)

{
    "question_id": "preference",
    "type": "singleselect",
    "query": "Who needs more support?",
    "values": ["{child1name}", "{child2name}", "Both equally"],
    "datatype": "text",
    "required": true
}

4. multiselect - Checkboxes (multiple choices)

{
    "question_id": "factors",
    "type": "multiselect",
    "query": "Which factors matter? (select all)",
    "values": ["Ability", "Effort", "Interest", "Future potential"],
    "datatype": "text",
    "required": true  // Note: multiselect always validates as true
}

5. grid - Table with radio buttons per row

{
    "question_id": "scenarios",
    "type": "grid",
    "query": "For each opportunity, who would you choose?",
    "prefixes": [
        "Extra tutoring",
        "Summer camp",
        "Music lessons"
    ],
    "options": [
        ["{child1name}", "{child2name}"],
        ["{child1name}", "{child2name}"],
        ["{child1name}", "{child2name}"]
    ],
    "required": true
}

6. mpl - Multiple Price List (with automatic logic)

Same structure as grid, but selecting option in row k automatically:

  • Selects first option for rows 1 to k-1
  • Selects second option for rows k+1 onwards
{
    "question_id": "price_list",
    "type": "mpl",
    "query": "Would you accept each offer?",
    "prefixes": ["$10", "$20", "$30", "$40"],
    "options": [
        ["Yes", "No"],
        ["Yes", "No"],
        ["Yes", "No"],
        ["Yes", "No"]
    ],
    "required": true
}

7. plaintext - Display text only (no input)

{
    "question_id": "instructions",
    "type": "plaintext",
    "text": "Next, we'll ask about {child1name} at {child1school}."
}

8. likert - Single Likert scale

{
    "question_id": "satisfaction",
    "type": "likert",
    "query": "How satisfied are you with {child1name}'s school performance?",
    "prefix": "Rate your satisfaction level",
    "min": 1,
    "max": 7,
    "required": true
}

9. multilikert - Multiple Likert scales with same range

{
    "question_id": "child_ratings",
    "type": "multilikert",
    "query": "Rate each child on the following aspects:",
    "prefixes": [
        "{child1name}'s academic performance",
        "{child1name}'s social skills",
        "{child2name}'s academic performance",
        "{child2name}'s social skills"
    ],
    "min": 0,
    "max": 10,
    "required": true
}

10. consent - Consent checkbox with text

{
    "question_id": "consent_form",
    "type": "consent",
    "query": "I agree to participate",
    "text": "<h5>Study Title</h5><p>Detailed consent information...</p>"
}

Common Fields

  • question_id: Unique identifier (required)
  • type: Question type (required)
  • query: Main question text (required for input questions)
  • datatype: “text” or “number” (for input questions)
  • required: true/false (defaults to false)
  • values: Array of choices (for select questions)
  • prefixes: Array of row labels (for multiopen/grid/mpl/multilikert)
  • options: 2D array of choices per row (for grid/mpl)
  • text: Display content (for plaintext/consent)
  • min: Minimum value for scale (for likert/multilikert, defaults to 0)
  • max: Maximum value for scale (for likert/multilikert, defaults to 5)
  • prefix: Descriptive text for single likert scale (for likert)

Summary of All Question Types

The survey system supports 10 different question types:

  1. consent - Consent form with detailed text
  2. plaintext - Display-only text (instructions, section headers)
  3. open - Single text or number input
  4. singleselect - Radio buttons (single choice)
  5. multiselect - Checkboxes (multiple choices)
  6. multiopen - Multiple labeled inputs
  7. grid - Table with radio buttons per row
  8. mpl - Multiple Price List with automatic selection logic
  9. likert - Single Likert scale (1-5, 1-7, 0-10, etc.)
  10. multilikert - Multiple items with same Likert scale

Enumerator Guide: Session Management App

Overview

This app helps you manage and conduct experimental sessions with children and parents. The app works offline, so you can collect data even without internet access.

1. Logging In

When to Log In

  • Only log in when you have internet access
  • Log in at the beginning of your data collection period
  • Your login credentials will identify you as the enumerator for all sessions you create

How to Log In

  1. Click the 🔑 Login button in the top right corner
  2. Enter your email address and password
  3. Click Login
  4. Once logged in, you’ll see your name and ID displayed in the top right

⚠️ Important Warning

DO NOT log out when there’s no internet connection! - If you log out without internet, you won’t be able to log back in - You can only log in when you have internet access - Stay logged in throughout your offline data collection period

2. Creating Sessions

Once logged in, your Enumerator ID will be automatically filled in when creating sessions.

Creating a Child Session

  1. Click 👶 New Child Session
  2. The form will appear with your Enumerator ID pre-filled (you cannot change it)
  3. Fill in the required information:
    • School: Select from the dropdown list
    • Family ID: Enter the family identifier
    • Child ID: Enter the child’s identifier
    • Child Name: Enter the child’s name
  4. Click Create Session

Creating a Parent Session

  1. Click 👨‍👩‍👧‍👦 New Parent Session
  2. The form will appear with your Enumerator ID pre-filled (you cannot change it)
  3. Fill in the required information:
    • School: Select from the dropdown list (determines if treatment or control group)
    • Family ID: Enter the family identifier
    • Child 1 Name: Enter the first child’s name
    • Child 2 Name: Enter the second child’s name
  4. Click Create Session

3. Running Sessions

Current Sessions Table

The 📝 Current Sessions table shows all sessions that haven’t been uploaded yet. Sessions are sorted with the newest at the top.

Table Columns:

  • Session ID: Unique identifier for the session (first 8 characters)
  • FamID: Family identifier
  • EnumID: Your enumerator ID
  • Session: Type (Child or Parent)
  • Status: Shows completion status
    • Incomplete: Not all components are finished
    • Ready to Upload: All components completed

Row Colors:

  • Light Blue: Child sessions
  • Light Green: Parent sessions

Starting a Session

For Child Sessions:

  1. Find the session in the Current Sessions table
  2. Click the Start button
  3. Complete the child questionnaire
  4. The session will automatically save your progress

For Parent Sessions:

  1. Find the session in the Current Sessions table
  2. Click the Start button
  3. Complete the required components:
    • Parent questionnaire (all groups)
    • Slider exercise (treatment group only)
    • Exit survey (treatment group only)
  4. The session will automatically save your progress

Understanding Session Status

  • Start button is blue/green: Session is ready to begin or continue
  • Start ✓ button is grayed out: Session is complete
  • Incomplete badge: Shows which components are still needed

4. Viewing Session Details

Why Check Details?

Always verify that data has been recorded correctly before uploading.

How to View Details

  1. Find the session in the Current Sessions or Uploaded Sessions table
  2. Click the Details button
  3. Review the session information:
    • Session Overview: IDs, dates, school information
    • Session Status: Completion status of each component
    • Survey Responses: All answers recorded
    • Slider Responses: Investment decisions (for treatment group parent sessions)

What to Check

  • ✅ All required components show as “Completed”
  • ✅ Survey responses are present and correct
  • ✅ Slider responses are recorded (for treatment parents)
  • ✅ Dates and times look reasonable

5. Uploading Completed Sessions

Requirements for Upload

  • ✅ You must be logged in
  • ✅ You must have internet access
  • ✅ The session must be complete (all components finished)

Understanding the Upload Button

The ⬆️ Upload Completed button changes based on your status:

When you’re NOT logged in or have NO completed sessions: - Button shows: “⬆️ Upload Completed” - Button is grayed out and disabled - You cannot upload

When you’re logged in AND have completed sessions: - Button shows: “⬆️ Upload X Completed Session(s)” (where X is the count) - Button is green and enabled - Click to upload all completed sessions

How to Upload

  1. Make sure you’re logged in and have internet
  2. Check the upload button:
    • If it’s green and shows a count, you have sessions ready to upload
    • If it’s gray, either you’re not logged in or no sessions are complete
  3. Click the Upload button
  4. The app will upload all completed sessions at once
  5. You’ll see a success message showing how many sessions were uploaded

After Upload

  • Uploaded sessions move to the ✅ Uploaded Sessions table
  • The upload timestamp is recorded
  • You can still view details of uploaded sessions for verification

6. Managing Sessions

Deleting a Session

If you need to delete a session (e.g., incorrect information):

  1. Find the session in the Current Sessions table
  2. Click the Delete button
  3. Confirm the deletion
  4. ⚠️ Warning: This cannot be undone!

Session Counts

At the top of the page, you’ll see:

  • Current: Number of sessions not yet uploaded
  • Uploaded: Number of sessions successfully uploaded
  • Total: Total number of sessions in the database

7. Troubleshooting

“I can’t log in”

  • ✅ Check that you have internet access
  • ✅ Verify your email and password are correct
  • ✅ Make sure you’re not already logged in

“The upload button is grayed out”

  • ✅ Verify you’re logged in (see your name in top right)
  • ✅ Check that you have internet access
  • ✅ Make sure sessions are complete (not showing “Incomplete”)
  • ✅ If the button shows “Upload Completed Sessions” (no number), you have no completed sessions ready

“My session status shows Incomplete”

  • Click Details to see which components are missing
  • Complete the missing components:
    • Child sessions: Child survey
    • Parent sessions (control): Parent survey
    • Parent sessions (treatment): Parent survey + Slider exercise + Exit survey

“I accidentally logged out without internet”

  • You’ll need to wait until you have internet access again to log back in
  • Your local sessions are safe and won’t be lost
  • Once you have internet, log in and continue as normal

8. Best Practices

At the Start of Your Day

  1. ✅ Connect to internet
  2. ✅ Log in to the app
  3. ✅ Verify you see your name and ID in the top right
  4. ✅ Keep the app open in your browser

During Data Collection (Offline)

  1. ✅ Create sessions as needed
  2. ✅ Run sessions with participants
  3. ✅ Verify session details after completion
  4. ✅ DO NOT log out

At the End of Your Day (With Internet)

  1. ✅ Connect to internet
  2. ✅ Verify you’re still logged in
  3. ✅ Check the upload button - it should show a count if sessions are ready
  4. ✅ Click the upload button to upload all completed sessions
  5. ✅ Verify uploads were successful
  6. ✅ Check the Uploaded Sessions table to confirm

Emergency: Reset Local Database

  • There’s a Reset Local DB button at the bottom of the page
  • ⚠️ DANGER: This deletes ALL sessions from your device
  • Only use if instructed by your supervisor
  • This does NOT affect sessions already uploaded to the server
